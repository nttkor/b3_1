# B6-1 — 시작 전 지식 체크

이 문서는 B6-1을 시작하기 전에 **웹 서비스 배포와 클라우드 네트워크를 이해하기 위한 최소 지식**이 준비되어 있는지 확인하는 자가진단입니다. 공식 평가나 Runtime Gate가 아닙니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B4-1
- **있으면 좋은 선행 지식:** Linux, TCP/IP, HTTP, Nginx/Web Server, Cloud Network 기초

## 자가진단

- [ ] 웹 브라우저가 HTTP로 서버에 요청한다는 흐름을 이해한다.
- [ ] IP 주소와 TCP Port의 기본 역할을 알고 있다.
- [ ] Linux에서 파일을 확인하고 기본 명령을 실행할 수 있다.
- [ ] Web Server가 HTTP 요청을 받아 응답하는 프로그램이라는 점을 이해한다.
- [ ] Public/Private Network 또는 Firewall이라는 개념을 본 적이 있다.
- [ ] Cloud의 VM/Instance가 원격 Linux 서버와 비슷한 역할을 한다는 점을 이해한다.

## 판단 방법

- 대부분 `예`라면 `BEGINNER-GUIDE.md`로 바로 진행합니다.
- 실제로 배포할 간단한 웹 결과물이 있으면 이해가 쉬우므로 B4-1 경험을 권장합니다.
- 네트워크나 Nginx가 처음이어도 B6-1에서 학습할 수 있으므로 시작을 막지 않습니다.

> **B4-1 CLEAR는 필수 조건이 아닙니다.** 웹/HTTP의 기본 흐름을 이미 이해한다면 바로 B6-1을 시작할 수 있습니다.
