# Round 01 — CLEAR

입문자가 공식 미션과 평가 기준을 바탕으로 단계별로 따라가며 미션을 완료합니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B4-1
- **있으면 좋은 선행 지식:** Linux, TCP/IP, HTTP, Nginx/Web Server, Cloud Network 기초

B4-1에서 실제 웹페이지를 만들어 본 뒤 배포 대상으로 사용하면 B6-1의 목적이 훨씬 명확해집니다. 다만 배포할 정적/웹 결과물이 이미 있거나 Web/HTTP 기초를 알고 있다면 B4-1을 CLEAR하지 않고도 B6-1을 시작할 수 있습니다.

진행 순서: `START-CHECK.md` → Mission 확인 → 용어/개념 → 환경 → 구현 → 검증 → Evidence → CLEAR.

핵심 문서:
- `START-CHECK.md` — Web/HTTP/Linux/Cloud 시작 전 자가진단
- `BEGINNER-GUIDE.md`
- `CHECKLIST.md`

`START-CHECK.md`는 공식 Gate가 아니라 부족한 Web/Network 개념을 미리 찾고 필요한 부분만 보충하기 위한 안내입니다.

상세 폴더와 파일은 실제로 필요해지는 시점에만 생성합니다.
